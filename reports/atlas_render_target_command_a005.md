# A-005 — Deferred render-target command construction and context forwarding (original SELF)

**Status:** independently verified original-target static finding; no runtime reachability claim. **Target:** Déraciné 1.00 SELF, size 81,506,767, SHA-256 `8caee78e40693b2e57c68ce87ce9507d907b824b6f6a4c481f414ac0627011a0` (rehashed this run). Existing A4 analysis at `research/a4-rhi-dispatch-20261121@6d08f2ffae4831aed93783c07289edfb924e211b` had identified vtable `0x03F26A28` and Execute `0x13A6A30`; those identities are **prior candidates**, not this finding.

## New original-byte-verified construction-to-Execute contract

1. The inner ELF RELRO vtable at **ELF VA `0x03F26A28`** contains two 64-bit entries: `0x13A6A30` and `0x13A6A70`. Its original SELF container offset is **`0x03F47C68`** (RELRO segment mapping `+0x21240`).
2. An independently decoded constructor block at **ELF VA `0x1420F77`** takes the address of this exact vtable and at `0x1420F86` writes it to `[rbx+0x00]`. At `0x1420F70`, `[list_tail]` is set to `rbx`; `0x1420F73` updates tail to `&rbx->Next`; `0x1420F7E` zeroes `[rbx+0x08]`. This establishes a concrete producer of this deferred command, not just an isolated function pointer.
3. Constructor `0x1420F89` writes the **32-bit count** at `[rbx+0x10]`. It initializes a repeated **0x18-byte descriptor stride** beginning at `[rbx+0x18]`, with pointers at `+0x18,+0x30,+0x48,+0x60,+0x78,+0x90,+0xA8,+0xC0`; adjacent slots `+8` and `+0x10` are initialized separately. The constructor also zeroes an embedded 16-byte field at `+0xD8` and a 32-bit field at `+0xE8`. The precise C++ type and ownership of each descriptor remain unknown.
4. The independently decoded `Execute` at **ELF VA `0x13A6A30`** loads the RHI context from `[command_list+0x20]` and passes **six arguments** to direct callee **ELF VA `0x0CC2420`**: `RDI=context`, `ESI=[command+0x10]`, `RDX=&command+0x18`, `RCX=&command+0xD8`, `R8D=[command+0xE8]`, `R9=&command+0xF0`, with seventh stack DWORD zero. The Execute call is at `0x13A6A62`.
5. The independently decoded callee `0x0CC2420` corroborates the array contract: `0x0CC24D8` stores the count at `[context+0x474]`; `0x0CC2500` loops through up to eight descriptor positions, advancing descriptor pointer by **0x18** at `0x0CC256F`. At `0x0CC2505` it loads the descriptor resource pointer; `0x0CC250D/0x0CC2511` read two adjacent DWORDs; `0x0CC251E` calls `0x0CC7E00` with context, slot index, resource, flags/metadata; `0x0CC2529` invokes the resource vtable slot `+0x38`. The null descriptor path at `0x0CC2550–0x0CC2563` calls the same helper with null resource. Thus this command performs resource-binding updates, not merely packet-buffer growth.
6. A further context mask `[context+0x518]` is cleared at `0x0CC24E7`, updated in the per-slot loop, and compared with `[context+0x514]` and `[context+0x510]` after the loop. This is concrete per-attachment state tracking, but not enough to name the bit semantics.

## Address provenance and limitations

All function addresses above are **inner ELF virtual addresses**, not original SELF offsets, relocated runtime guest pointers, GPU VAs, or shader hashes. For executable code in this region the checked SELF container mapping is **ELF VA + `0x1FD30`**: constructor `0x1420F77 -> SELF 0x1440CA7`, Execute `0x13A6A30 -> SELF 0x13C6760`, context callee `0x0CC2420 -> SELF 0x0CE2150`. RELRO uses its own segment mapping, above. No live execution was inferred.

**Interpretation:** high confidence this is a deferred render-target/attachment binding command with a counted fixed-stride resource descriptor array. The name `FRHICommandSetRenderTargets` remains a strong **A4/source-informed hypothesis**, not recovered C++ RTTI. Eight slots, the vtable call at resource `+0x38`, and context state masks require ownership/type corroboration; no resource lifetime conclusion is claimed.

**Competing interpretation:** a PS4-specific render-target binding/resolve variant could share the same descriptor pattern; the exact role of `+0xD8/+0xE8/+0xF0` and resource vtable slot `+0x38` is not proven.
